# サンプル問題データ

スプレッドシートに貼り付けて使うサンプル。TSV（タブ区切り）なので、
ファイルの中身をコピーして各シートの **A1セル** に貼り付けると、列に分かれて入る。

| ファイル | 貼り付け先のシート名 | 件数 |
|----------|---------------------|------|
| `クイズ.tsv` | クイズ | 10問 |
| `写真クイズ.tsv` | 写真クイズ | 8問 |
| `文字並べ替え.tsv` | 文字並べ替え | 12問 |
| `クロスワード.tsv` | クロスワード | 8問 |
| `絵合わせ.tsv` | 絵合わせ | 12ペア |

シート名はこの表のとおりに作ること（[config.js](../config.js) で指定されている名前と
一致しないとゲームがデータを見つけられない）。

## 列構成のきまり

**全ゲーム共通で A列は番号**、実データは B列から始まる。
番号は画面には表示されない、シート上で問題を管理するための通し番号。

1行目は見出し行。ゲームは2行目以降を読むので、見出し行はそのまま残しておく。

## 各シートの注意点

### 写真クイズ

画像URLは Wikimedia Commons のもの（自由に使えるライセンス）を使用。
本番では地域の写真に差し替えると喜ばれる。Googleドライブの共有URLを貼っても
自動でサムネイルURLに変換される。

**「シルエット」形式について**: I列に `シルエット` と書くと、画像が
`filter: brightness(0)` で真っ黒に塗りつぶされて表示される。つまり
**背景が白（または透過）の切り抜き画像でないと、ただの黒い四角になる**。
ふつうの風景写真をシルエットにすると画面が真っ黒になるので注意。
そのためサンプルはすべて `写真` 形式にしてある。

### 文字並べ替え

C列の正解の文字数が、そのまま文字カードの枚数になる。カード1枚が58pxなので、
スマホ画面（480px）では**4〜6文字**がちょうどよい。長すぎると折り返して見づらくなる。
サンプルはすべて4〜6文字にしてある。

### クロスワード

B列（横単語）とC列（縦単語）に**共通する文字が必ず1つ以上必要**。
共通文字がない行は自動的にスキップされて出題されない。

D列のヒントは `横のヒント/縦のヒント` の形式。区切りは**半角スラッシュ `/`**。
全角の `／` では分割されないので注意。

### 絵合わせ

C列（画像URL）が空なら、D列の絵文字が表示される。両方入っていれば画像が優先。
サンプルは絵文字だけを使っているので、画像を用意しなくてもそのまま遊べる。

ペア数は「設定」シートの `絵合わせペア数` で 6/8/10/12 から選ぶ。
サンプルは12ペア分あるので、どの設定でも足りる。
