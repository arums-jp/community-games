# サンプル問題データ

スプレッドシートに貼り付けて使うサンプル。TSV（タブ区切り）なので、
ファイルの中身をコピーして各シートの **A1セル** に貼り付けると列に分かれて入ります。

| ファイル | 貼り付け先のシート |
|----------|--------------------|
| `写真クイズ.tsv` | 写真クイズ |
| `文字並べ替え.tsv` | 文字並べ替え |

1行目は見出し行。ゲームは2行目以降を読むので、見出し行はそのまま残しておく。

## 写真クイズについて

画像URLは Wikimedia Commons のもの（自由に使えるライセンス）を使用。
本番では地域の写真に差し替えると喜ばれる。Googleドライブの共有URLを貼っても
自動でサムネイルURLに変換される。

**「シルエット」形式について**: 出題形式の列に `シルエット` と書くと、画像が
`filter: brightness(0)` で真っ黒に塗りつぶされて表示される。つまり
**背景が白（または透過）の切り抜き画像でないと、ただの黒い四角になってしまう**。
ふつうの風景写真をシルエットにすると画面が真っ黒になるので注意。
そのためサンプルはすべて `写真` 形式にしてある。
シルエットを使いたい場合は、背景を白く抜いた画像を用意すること。

## 文字並べ替えについて

C列の正解の文字数がそのまま文字カードの枚数になる。カード1枚が58pxなので、
スマホ画面（480px）では**4〜6文字**がちょうどよい。長すぎると折り返して見づらくなる。
サンプルはすべて4〜6文字にしてある。

B列（予備項目）は現在ゲーム側で使っていないので空でよい。
